# D7. 시간은 날짜를 주 라벨로, 경과를 보조로 표기한다

> 확정 · 2026-09 · **초안을 번복한 결정**

## 상황

D3에서 메시지를 영구 저장하기로 하면서 스크롤이 몇 달·몇 년에 걸치게 됐다.
날짜 구분선이 **정보가 아니라 이 서비스의 시그니처 UI**가 되는 셈이라, 표기 방식을 정해야 했다.

## 초안 — 직전 블록 기준 (폐기)

```
────── 2025년 4월 ──────
   ...
────── 8개월 후 ──────
   ...
────── 어제 ──────
```

영화 자막처럼 생각했다. 스크롤을 내려가며 시간을 통과하는 연출을 노렸고,
`8개월 후` 는 몽타주 전환 카드 역할이었다.

**폐기 이유 셋.**

| | 문제 |
|---|---|
| **스크롤 방향** | 채팅 스크롤은 **위로 올릴수록 과거**다. 주된 이동 방향이 과거 쪽인데 "N 후"는 아래로 내려올 때만 성립한다 |
| **체인 의존** | 앞 라벨을 알아야 현재 위치를 안다. 중간부터 읽으면 해석이 안 된다 |
| **기준이 섞임** | `2025년 4월`(절대) → `8개월 후`(직전 기준) → `어제`(현재 기준). 한 화면에서 기준이 세 번 바뀐다 |

연출을 먼저 생각하고 **읽기 동작을 나중에 생각한** 것이 실수였다.

## 결정

**날짜가 주 라벨, 현재 기준 경과가 보조.** 둘 다 가운데 정렬해 하나의 도장처럼 읽히게 한다.

```
────── 2025년 4월 12일 ──────
        1년 5개월 전
```

- **날짜** — 변하지 않는 사실. 계절 맥락을 담는다 (4월 = 벚꽃)
- **경과** — 지금 시점의 해석. "얼마나 된 거야"에 즉답한다

역할 분담이 핵심이다. 상대 표기만 쓰면 같은 글의 라벨이 시간에 따라 계속 변하고
(오늘 "6개월 전" → 내년 "1년 6개월 전") 계절 맥락도 사라진다.
날짜만 쓰면 얼마나 오래됐는지 매번 계산해야 한다.

### 포맷

| 조건 | 주 라벨 | 보조 |
|---|---|---|
| 오늘 | `2026년 9월 23일` | `오늘` |
| 어제 | `2026년 9월 22일` | `어제` |
| 7일 이내 | `2026년 9월 18일` | `5일 전` |
| 1년 이내 | `2025년 12월 3일` | `9개월 전` |
| 1년 이상 | `2025년 4월 12일` | `1년 5개월 전` |

주 라벨은 **항상 `YYYY년 M월 D일`**. 오늘·어제도 날짜를 그대로 쓴다 —
둘 다 "어느 날"을 가리키는 말이라 절대 날짜와 같은 기준이다.

### 큰 공백은 색이 아니라 여백으로

직전 블록과 **3개월 이상** 벌어지면 구분선 위 여백을 넓힌다.

```
기본     margin-top  14
큰 공백  margin-top  56
```

처음엔 색(틸)으로 강조했다가 두 가지 이유로 뺐다.

**① 강조 위치가 규칙과 어긋났다.** 샘플에서 실제로 더 큰 공백은 아래쪽(9.6개월)인데
위쪽(8개월)을 강조하고 있었다.

**② 색은 "멀다"를 뜻하지 않는다.** 색은 위계를, 여백은 거리를 말한다.
**시간 거리를 공간 거리로** 표현하면 은유가 맞고, 스크롤로 넘기는 데 실제로 더 오래 걸린다.

## 결과

### API 계약이 정해졌다

서버는 `createdAt`(ISO 8601) **원본만** 내려준다. "9개월 전" 같은 문자열을 만들지 않는다.

> 서버가 만들어 보내면 앱이 백그라운드에 오래 머물렀을 때 값이 굳는다.
> **렌더링 시점에 앱이 계산**해야 정확하다.

`app/src/lib/time.ts` 의 `formatDate` · `formatRelative` 가 이 역할을 한다.

### 구분선이 섹션 헤더가 됐다

날짜 블록이 곧 섹션이므로 `SectionList` 구조가 자연스럽게 따라왔다.
직전 블록과의 간격은 섹션이 다 만들어진 뒤에야 알 수 있어, `isWideGap` 을 후처리로 계산한다.

## 번복

**쉽다.** 값(3개월 기준, 여백 14/56)은 상수이고, 포맷은 `time.ts` 한 곳에 모여 있다.

여백 값은 **실제 데이터로 스크롤을 채워본 뒤 조정할 값**으로 본다.
지금 샘플은 공백이 둘 다 커서 대비가 체감되지 않는다.
